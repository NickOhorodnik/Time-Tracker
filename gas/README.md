# Allonsy Time Tracker — Контейнерний Google Apps Script (BYO Bound Sheet)

Ця папка містить серверний код для власної копії Google Таблиці. Кожен користувач розгортає свій Apps Script і в налаштуваннях додатка вказує URL вебпрограми та власну таблицю. Окремий вхід у додаток або ручний запуск функцій у редакторі не потрібні.

## Склад пакета `/gas/`
- `Code.gs` — серверний скрипт. Кожен запит отримує посилання на таблицю з налаштувань користувача та відкриває лише її.

- `Index.html` — головний HTML-шаблон `HtmlService` (підключає `Styles`, `AssetsManifest`, `Assets_*.html` та `AppScript` через `include()`).
- `Styles.html` — скомпільований CSS застосунку.
- `AssetsManifest.html` — згенерований маніфест вбудованих зображень.
- `Assets_01.html` — HTML partial-файл із вбудованими ресурсами зображень.
- `AppScript.html` — скомпільований production IIFE React-бандл застосунку.
- `appsscript.json` — маніфест Apps Script (`USER_ACCESSING`, `ANYONE`, V8, `Europe/Kyiv`).

## Канонічні аркуші (пасивна перевірка схеми без автоматичних мутацій)
- `Записи` (та місячні розділи, напр. `2026-11`) — записи часу (`segment_id`, `session_id`, `command_id`, `дата`, `початок_utc`, `кінець_utc`, `секунд`, `category_id`, `категорія_назва`, `action_id`, `project_id`, `employee_id`, `related_employee_id`, `опис`, `джерело`, `month_key`, `updated_at_utc`, `deleted_at_utc`).
- `Працівники` (`employee_id`, `name`, `role`, `status`, ...), `Оцінки` (`rating_id`, `employee_id`, `score`, ...).
- `Категорії`, `Типи дій`, `Проєкти`, `Бонуси`, `Отримані бонуси` (`claim_id`, `bonus_id`, `назва_на_момент_запиту`, `employee_id`, `quantity`, `unit_price_points`, `вартість_балів`, `дата_запиту_utc`, `статус`, `дата_отримання_utc`, `коментар`, `command_id`, `updated_at_utc`, `approved_by_employee_id`, `approved_at_utc`, `points_transaction_id`, `eligibility_id`).
- `Ролі балів`, `Профілі балів`, `Причини балів`, `Операції балів`, `Періоди балів`, `Доступність бонусів` — конфігурація ролей (`Керівник` / `Виконавець`), персональних профілів, довідника причин, незмінного журналу операцій, закриття періодів і правил доступності бонусів.
- `Фрази`, `Мотиваційні фрази`, `Бібліотека зображень`, `Призначення зображень`, `Налаштування`, `Журнал змін`.

## Рольова система балів і захист мутацій
- Кожна команда використовує власну копію таблиці без жорстко зашитих імен працівників, ID чи фіксованого каталогу бонусів.
- Описова посада на аркуші `Працівники` (`role`) зберігається окремо від ролі балів (`points_role` у `Профілі балів`).
- Привілейовані серверні операції (`gasExecutePointsCommand`: зміна ролей, профілів, причин, доступності бонусів, ручні нарахування/списання, сторнування, закриття періоду, погодження/скасування бонусів) перевіряють особу користувача через `Session.getActiveUser().getEmail()` та доступ власника/редактора Google Таблиці.
- У поточному анонімному режимі вебпрограми (`access: ANYONE` / проксі `/api/gas-proxy`) підтверджений email порожній, тому сервер навмисно блокує такі мутації з кодом `AUTH_REQUIRED_PRIVILEGED_MUTATION` (призначення ролі `manager` у таблиці не надає прав адміністратора).

## Відтворюване перезбирання пакета
Щоб перегенерувати `Index.html`, `Styles.html`, `AssetsManifest.html`, `Assets_*.html` і `AppScript.html` із вихідного коду React:
```bash
npm run build:gas
```

## Підключення

1. Зробіть власну копію шаблону Google Таблиці.
2. Відкрийте в копії «Розширення → Apps Script» та вставте серверний код трекера з `Code.gs`. Збережіть проєкт.
3. Один раз запустіть приватну функцію `initializeBoundSpreadsheet_()` у редакторі Apps Script (прив’яже ID таблиці у `ScriptProperties` цього скрипту без зміни даних таблиці).
4. Розгорніть вебпрограму від імені власника скрипту або користувача та скопіюйте URL `/exec`.
5. У налаштуваннях додатка збережіть URL вебпрограми й посилання на свою Google Таблицю.
6. Натисніть «Перевірити підключення», потім «Завантажити з таблиці».

Кожен користувач підключає власну копію таблиці та власне розгортання Apps Script. Додаток не зберігає спільний Spreadsheet ID між різними проєктами.
